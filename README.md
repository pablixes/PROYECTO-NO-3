# PROYECTO-NO-3
Simulacion para una incubadora neonatal

Para desarrollar el proyecto se utilizaron dos microcontroladores NUCLEO-F446RE y un ESP32 DevKit V1, distribuyendo las funciones de adquisición de datos, comunicación, visualización y almacenamiento. El sistema se diseñó como un prototipo de monitoreo para una incubadora neonatal, utilizando un sensor AHT10 para medir temperatura y humedad. También se implementó una pantalla TFT ILI9341, una tarjeta microSD de 32 GB, un indicador NeoPixel y un circuito de audio controlado mediante DAC.
